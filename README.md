# AEOLUS — The Breath That Powers the World

An interactive, Renaissance-painted journey through wind energy: flowing wind particles, a da Vinci–style turbine anatomy, a spin-your-own-turbine physics lab, the Betz limit, live global wind stats (GWEC Global Wind Report 2026) and a Myth or Fact quiz.

Pure HTML/CSS/JS, no build step. Open `index.html` or host with GitHub Pages.

Paintings are AI-generated in classical styles.
